# FinAgent 安全自评报告

版本：P1候选，2026-10-15。产品为本地模拟银行；以下按用户提供的赛题任务原文自评，不代替赛会官方认可。

## 权限实现

| 赛题要求 | 实现与位置 | 验证/残余限制 |
|---|---|---|
| 绿色自动 | 账户、流水、账单、理财事实查询由领域服务返回 | HTTP与浏览器/专项测试；订阅查询按题目保留黄色确认 |
| 黄色确认 | 固定条款、快照、会话和CSRF；小额转账、虚拟卡申请、订阅取消等 | 100元转账页面确认；聊天确认不授权 |
| 红色强验证 | `domain/security.py`；跨本人账户真实上海日累计含本笔>1000元；申购、挂失等固定红色 | 随机本机模拟短信、180秒、操作绑定、一次核销；不是真实短信或真实银行登录 |
| 并发复验 | SQLite短写事务内重算累计、余额、条款及任务控制 | 并发黄单不能绕过阈值，改参/重放被拒 |
| 后台授权 | 预约一次、生日有界商品采购、代扣12次/366天 | 到期重查条款/次数/锁，失败不无界重放 |

## 五类安全机制

| 要求 | 设计与实测 | 自评 |
|---|---|---|
| 幻觉防护 | 工具结果与回执来自数据库；未知、未付款、待送达均有明确状态；缺覆盖为null；异常仅候选 | 后端边界与替身模型通过；真实模型红队仍需补充 |
| 注入防御 | 严格Schema、工具白名单、归属和授权不由模型提供；不开放确认工具 | 已测伪造授权、跨用户、未知工具；间接注入真实模型全集未完成 |
| 操作审计 | 消息、步骤、策略版本、结构化违规、业务资源/回执，新增任务审计接口 | 能按任务追溯；worker全链路统一trace尚未齐全 |
| 异常熔断 | 5次认证失败锁15分钟；持久化覆盖前台与后台，模型网络故障不当攻击 | 锁定/跨会话/后台停止测试；疑似行为分类规则仍有限 |
| 沙箱 | `-I -S`受限信封校验进程、64KiB输入、2秒超时；文件/网络/执行审计拒绝 | 已测拒绝及真实进程超时终止；不执行生成代码，Docker资源/网络隔离尚未验收，赛方口径待确认 |

## 角色与隐私

用户确认只提交卡申请；独立本机审批凭据才模拟发卡，坐席仅澄清、终止和交还任务。AA成员付款、采购和配送仍是明确标注的模拟通道，不能当作真实身份认证。单机OS管理员能访问密钥与数据库，角色隔离不是对恶意管理员的防护。

外部模型字段、文本脱敏边界、本地无限期保留和后台停机策略见 [隐私与调度策略](P1-隐私与调度策略.md)。没有对未知自由文本个人信息作绝对不泄露承诺。

## 已知风险与未放行项

1. 模拟会话/短信、银行转账、审批、商户和送达不是真实接入；赛方接受程度未取得答复。
2. 受限自然语言和单写DAG不等于任意多目标自动办理；复杂约束可能保守拒绝。
3. SQLite适合本机演示，不提供生产多节点银行系统的可用性和运维保障。
4. 全链路trace、完整真实Live对抗集、容器边界、干净机器独立复现仍需补验；成绩以当前验收记录为准。
5. 真实供应商或银行错误恢复、已付款退款补偿不在当前能力内；不可删除流水假装回滚。
6. 最终PPT/视频、GitHub可访问性、材料上传及团队知识产权声明须由参赛团队核对完成。

正式提交前应将当前测试报告、源码摘要和材料版本绑定，并由团队复核上述限制；本报告不声明已通过赛事审核。
