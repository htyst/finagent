# G01 第二阶段：持久检查点与局部重规划

2026-10-18。延续 `context_json.dynamic_runtime` 和 g01-v1，不建立第二套调度器。字段增量兼容现有前端；无数据库表迁移，Alembic 仍为 `0017_servicing`。

## 当前职责

- `agent/checkpoints.py`：当前目标、用户约束原话、证据版本、等待单据、授权期限、失败分类和继续入口随原运行状态持久保存。
- `agent/execution_graph.py`：校验归属、无环、引用、版本及状态转换，从实际工具结果与回执推导目标状态。
- `agent/dynamic_runtime.py`：串行动态工具循环；新消息更新请求屏障，继承有效执行记录。查询、计算、准备单、页面授权与实际提交继续分离。
- `declare_goals`：新增用户明确目标；跨轮增加唯一 ID，不能覆盖原目标。
- `revise_goals`：只修改、取消或继续已有目标；要求本人任务目标 ID 和本轮精确原话，不授予执行权。金额规范化复用现有中文数字、单位及改口校验，不把“八千”与 `8000` 当作不同预算。

模型可以选择查询、计算与准备工具；身份、归属、权限分级、凭据、认证、提交、幂等和交易成功仍由既有服务端决定。聊天“确认”不产生授权。

## 失效规则

| 触发 | 处理 | 保留 |
| --- | --- | --- |
| 用户更正预算、期限 | 先按现有 F01 原话校验屏障停用旧用户派生计算，再更新约束并按实际依赖使下游失效 | 未受影响的本人查询、独立应急金预留计算、既有回执 |
| 目标更新校验失败 | 记录 `revision_pending`；关联计算与回答不能绕过更新，修复参数后再继续 | 查询证据和失败尝试 |
| 取消一个目标 | 停止关联未执行操作；共享操作存在其他目标时要求澄清，不擅自取消 | 共享查询及已发生写入 |
| 本人账户/卡片/收款人版本、追加账本或相关业务状态变化 | 本人财务读取、计算及真实依赖后继保守失效；重新取证 | 历史记录与真实回执 |
| 受保护订阅跨轮读取 | 停用旧查询证据，按当前范围走原黄色查询确认 | 取消代扣仍须单独固定单 |
| 计划版本改变 | 原授权绑定失效；未受影响待办更新等待标识，仍须页面重新获取本版本授权 | 已确认真实回执 |
| 换用户、会话或数据集 | 原归属校验拒绝复用 | 原拥有者的持久记录 |

失效是标记历史记录不可再参与本轮计算，**不会把已付款项写成撤回**。数据版本键包括本人、会话、数据集和资源版本；查询复用还须精确匹配工具及参数，因此期间、范围、账户和用户不会混用。导入档案在数据集版本内按不可变快照处理；不支持绕过应用直接修改 SQL 后仍保证缓存正确。

## 恢复与结果未知

恢复先读取领域回执及原幂等结果。成功业务只补记原节点和回执，不调用提交器。中断读取标记 `INTERRUPTED_READ`，由后续合法查询继续；没有可靠资源或回执可核对的准备节点标记 `RESULT_UNKNOWN`、`waiting_verification`，阻止对同目标再次准备付款。

原工具调用仍在消息历史时按正常 `tool_call_id` 返回结果；跨轮已压缩历史时以明确标识的只读服务端检查点数据提供真实结果，不向 Chat Completions 伪造新工具调用。协议依据：[DeepSeek Tool Calls](http<本机路径已省略>

插问新增目标并保留原待办。浏览器持续使用当前对话，已完成付款后的追问仍保留同任务回执；取消或到期后创建新任务；“新对话”创建新任务入口，服务端保留原任务及回执，可按任务 ID 查询。成功付款后模型断网，固定单回执与目标进度可独立读取。

## 升级、保护与限制

修改前代码快照及运行库只读摘要：`var/reviews/remaining-20261018/before/`、`before.json`。测试均使用 TEST-ONLY。未重置运行数据库、未删除回执、未改本地密钥；最终数据库核对见本轮摘要。

没有 SQL 迁移。部署先停止应用进程，用 SQLite backup API 备份完整运行库（包含日志/回执），再替换代码并启动。若启动失败保留当前库和错误，优先前向修复；**产生新业务后不能用旧库备份覆盖当前库**。回退旧后端前在副本验证增量 JSON 字段兼容；旧版本严格 Schema 不保证能直接读取新增字段。

本轮仍为串行。单任务最多 8 个目标、64 个调用记录及既有 3 次准备上限；达到任务容量时需新对话，并引用原任务继续未办事项。不是通用无限并行调度系统；结果未知也不会自动重试支付。没有新增真实银行、真实短信或第三方撤回能力。
