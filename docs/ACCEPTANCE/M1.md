# M1 验收记录

- 日期：2026-09-24
- 阶段：可启动骨架、固定合成数据、演示会话和只读路径。
- 环境：Windows PowerShell 7.6.5；本机 Python 3.12.10（另有 3.14）；Node v24.14.0；npm 11.9.0；Git 2.54.0.windows.1。
- 数据：SQLite `var/finagent.sqlite3`；种子 `m1-2026-09-24-1`；演示日期 2026-09-24；每次重置生成新 `dataset_version`。
- 运行模式：应用 `mock`；DeepSeek `live` 仅作独立适配小试验，不声称完整 Agent 已集成。

## 实现和设计

1. `backend/app/data/`、`backend/migrations/`：SQLite 外键和金额/余额约束，用户、会话、账户、卡、收款人、流水及覆盖范围模型；Alembic 初始迁移；相对演示日期的固定种子与账本核对。主用户活期/储蓄余额为 10000/20000 元，餐饮消费和退款为后续 M2 留下可计算证据。
2. `backend/app/main.py`：演示用户选择与会话 cookie、过期和数据版本校验；本人账户、卡、收款人、流水分页只读接口。跨用户资源 ID 返回统一 404。模式和演示日期由数据/配置提供。
3. `frontend/`：响应式账户、卡片和分页流水页面，用户切换清除旧状态，刷新从服务端会话恢复。明确标示合成数据和 `mock` 模式。
4. `scripts/`：安装、项目范围内安全重置、启动与进程清理、M1 检查以及独立模型试验。Python/前端依赖分别由 `backend/requirements.lock`、`frontend/package-lock.json` 固定。
5. `backend/app/agent/smoke.py`：仅验证 DeepSeek 只读工具、严格参数和缺信息追问；没有执行工具，也没有模型可用的提交接口。依据 [DeepSeek Tool Calls 文档](https://api-docs.deepseek.com/guides/tool_calls/)与[思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)选择 beta 严格模式及非思考调用。
