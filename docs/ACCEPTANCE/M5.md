## 核心边界证据

- B16：主用户餐饮净消费 1,200 元准备成立，确认前新增 800 元退款后变为 400 元；返回 `CONDITION_NOT_MET`，无 TransferOrder、无扣款，写步骤跳过，固定区间和最新证据保留。
- B18：确认内条件检查处设置同步点，独立连接尝试 `BEGIN IMMEDIATE` 被锁拒绝；释放后仅一次转账。条件判断与提交之间不存在其他写入窗口。
- B15：准备已提交但调用中断，操作单与 Agent 关联仍在；恢复不调用模型、不多建单。写成功但后续余额读取异常，保留冻结回执；新会话连接恢复并只重试余额，业务结果仍一条。
- B17：分别控制确认先获锁和全任务取消先获锁；确认先成功时保留成功回执，任务部分完成，余额步骤取消；取消先成功时无卡业务。无“已执行改为取消”的误报。
- A06–A08：条件不成立/数据覆盖缺失不写；尾号不符跳过冻结；多笔消费必须明确选定；冻结失败或仅拒绝冻结继续独立余额；整任务取消停止后续步骤；余额失败可单独重试。
- 交易金额/时间/状态/卡关联与卡资源快照均在确认复核；条件仍成立但资源版本变化要求新单、新确认。修改阈值生成新计划版本并使旧单失效。
