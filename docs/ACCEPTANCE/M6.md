## 七组新增浏览器场景

| 场景 | 核对证据 |
| --- | --- |
| lost-response | 服务端确认成功后丢弃响应，首次任务读取也失败；确认按钮禁用，只读恢复后显示原回执；确认 POST 仅一次，TransferOrder/BusinessResult 各一条，活期 9,900 元；刷新后不重复写；终态超过两个轮询周期无新任务轮询 |
| portfolio-order | 手动控制确认前账户查询晚于确认后返回；旧 10,000 元响应不能覆盖新 9,900 元，数据库亦为 9,900 元 |
| same-user-new-session | u1→u2→u1 建立新会话后释放旧 u1 的 401 错误，新会话与两账户仍保留 |
| tabs-and-expiry | 另一标签页取消后本页自动同步；服务端操作单过期后确认按钮消失、无业务写入 |
| old-read-and-user-switch | 取消后释放旧待确认响应，不恢复旧确认按钮；其他标签页切换用户后旧页清空私有数据、显示重选提示 |
| changed-condition-and-chart | 确认前 800 元退款将餐饮净消费 1,200→400 元，不扣款，余额 10,800 元、业务结果零条；分类聚合图正确，单日 -800 元为左侧负条，覆盖删除后显示已知小计 |
| mobile-keyboard | 360×800 下用键盘输入及 Enter 确认转账、取消冻结、展开手动表单；确认后余额 9,900 元，取消后卡仍正常；页面及展开表单均无水平溢出 |

新增后端测试确认预期用户不一致时，账户、任务、CSRF 和确认凭据端点均返回 `SESSION_CHANGED`，响应无私有数据。请求头不提供身份授权，确认仍依赖服务端会话与 CSRF。
