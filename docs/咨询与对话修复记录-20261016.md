# 咨询与对话修复记录（2026-10-16）

## 理财咨询误进入交易流程

现象：输入“理财建议”后，助手要求产品、付款账户和转账金额。

原因：旧提示把“推荐”归入模拟理财产品流程，且所有理财意图共用交易回答限制；模型误判为澄清时，后端直接使用交易缺项模板。多轮上下文中还保留着上一笔业务资料。

修复：新增独立只读意图 `wealth_guidance`，明确区分通用咨询、具体产品比较、申购和赎回。Live 仍先调用模型理解；对整句明确的通用建议请求增加服务端边界，在整轮工具查询与回答中保持只读，清除该轮模型输出的交易参数，不推进原交易草稿。建议先提供资金用途、流动性、风险与费用等通用方法，再了解目标或期限。知识检索拥有版本与来源；拒绝从日期、URL、工具编号中为配置数字寻找“依据”。

新增验证包含：新对话直接问建议；误返回交易澄清；工具查询后模型误转申购；转账资料尚缺时切换理财咨询；明确申购及混合请求不被整句咨询规则覆盖；无依据数值与交易模板不显示。

## 同批完成的既有对话修复

- 自我介绍和通用教育问题检索能力知识，不再机械回答“没有足够业务证据”。
- 订阅查询未获授权时，在聊天内展示确认卡；用户点击后按保存范围继续查询，无需重新提问。确认仅授予本人当前会话的短时查询权限，不开通后台扣款或解除代扣。旧问题按钮失效、跨用户拒绝、重复点击幂等。

- 修复消费统计后继续异常筛查时，不兼容的继承字段导致后端异常的问题。真实筛选条件不被悄悄扩大。
