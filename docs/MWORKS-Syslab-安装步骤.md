# MWORKS.Syslab 2026b 安装步骤

> 依据：ISO 内官方《MWORKS.Syslab-2026b-win-x64-安装与配置说明书》原文提取（说明书是扫描件，已逐页解码正文）。
> 待装版本：`MWORKS.Syslab-2026b-26.6.1.8422-win-x64`

---

## ⚠️ 先解决这个，否则装到一半必失败

### 1. C 盘空间不够（最可能卡住你的问题）

说明书 **§1.1 运行环境** 的硬要求：

| 项目 | 最低 | 推荐 |
|---|---|---|
| 存储 | **20 GB** | **100 GB** |
| 内存 | 8 GB | 16 GB |
| CPU | 1 GHz / 2 核 | 2 GHz / 4 核 |
| 系统 | Windows 10/11 **64 位** | 同 |

**你现在的 C 盘只剩 7.3 GB，低于最低要求。**

而且有个**改不掉的坑**：说明书 §1.1 明确写

> "用户可自主选择软件安装路径，**Syslab 客户端仓库路径不可变更**，默认安装在
> `C:\Users\Public\TongYuan\.julia`"

也就是说——**主程序可以装到 D 盘，但那个 Julia 仓库仍然强制落在 C 盘**。
（已确认 `C:\Users\Public\TongYuan` 目前不存在，说明是首次安装。）

**先把 C 盘腾出至少 20 GB（建议 30 GB 以上留余量），再开始安装。**

### 2. 安装路径不能有中文

说明书两处都强调：

- §2.1(4)："**安装路径不支持中文路径**"
- §6.2.3："Syslab IDE 依赖第三方软件 `julia.exe`，**julia.exe 对中文路径的支持较弱**…建议在英文路径下安装"

所以别装到 `D:\软件\` 这类目录。用 `D:\MWORKS\Syslab` 这种纯英文路径。

### 3. 安装全程别关杀毒软件的弹窗

§6.1.2：杀毒软件弹警告时，**默认 30 秒不操作或选择"不允许"，安装直接失败**。
弹窗出现时要选"**允许程序所有操作**"并勾选"不再提醒"。
如果你用的是 360，被拦了要去 **系统修复 → 信任区 → 已阻止区** 把 Syslab 加回信任列表。

## 安装步骤

### 第 1 步：挂载 ISO

说明书 §2.1(1)：*"推荐使用 Windows 资源管理器打开"*。

**双击** `%USERPROFILE%\Downloads\MWORKS.Syslab-2026b-26.6.1.8422-win-x64.iso`
（或右键 → 装载），会多出一个光驱盘符。

> **不要**用 WinRAR / UltraISO 解压出来装。说明书 §6.1.1 明确写了这条坑：
> 那样虽然也能双击 exe，但**安装过程中不能关闭 WinRAR/UltraISO，否则报
> `[Errno 2] No such file or directory`**。挂载成光驱没这个问题。

### 第 2 步：启动安装程序

进光驱，双击 **`Syslab-2026b-26.6.1-win-x64.exe`**（228.5 MB）。
安装向导会去同目录的 `data\` 读资源，**所以整个安装过程不要让光驱弹出**。

### 第 3 步：选择安装方式

| 选择 | 做法 |
|---|---|
| **默认安装** | 勾选"同意用户许可协议" → 点 **立即安装**（会装到 `C:\Program Files\MWORKS\Syslab`） |
| **自定义设置**（推荐，因为你 C 盘紧张） | 点 **自定义设置** → 把安装路径改成 **`D:\MWORKS\Syslab`** |

自定义页面里：
- **选择产品**：说明书建议**全部安装**
- **选择安装路径**：默认 `C:\Program Files\MWORKS\Syslab`，点"浏览"改到 D 盘
- 勾选"同意 MWORKS.Syslab 的用户许可协议"

### 第 4 步：等安装完成

点 **立即安装**，等进度走完。

### 第 5 步：设置文件关联

会让你选关联哪些扩展名：**`.jl`** 和 **`.jld2`**（Julia 源文件和数据文件）。按需勾选。

### 第 6 步：完成

点 **安装完成**。检查两处：

- 桌面快捷方式：`MWORKS.Syslab2026b (x64)`
- 开始菜单程序组：`MWORKS.Syslab2026b`，里面有两个 —— `MWORKS.Syslab2026b (x64)`（启动）和 `uninstall (x64)`（卸载）

## 装完必须做：配置 License

说明书 §3：**未授权时软件标题会显示"演示版"，功能受限。**

三种激活方式，选一种：

| 方式 | 适用 | 做法要点 |
|---|---|---|
| **同元账号**（个人用户推荐） | 联网 | 注册/登录同元账号 → "帮助 > 使用许可 > 同元账号 > 登录"。若账号已有授权会自动激活；没有就点左下角"**前往申请**"去申请，通过后回到"使用许可"选"同元账号"点"**激活**" |
| 许可证服务器 | 企业集中管控 | 填服务器地址，终端连服务器激活 |
| 许可证文件 | 单机 / 无网络 | 导入本地 License 文件，支持离线 |

## 遇到问题先查这几条

| 现象 | 原因 | 解决 |
|---|---|---|
| 双击图标**没反应** | 显卡驱动和 Electron 版本不兼容 | 右键快捷方式 → 属性 → 在"**目标**"末尾加一个空格再加 `--no-sandbox` → 确定（§6.2.1） |
| 启动报错 | 当前用户对 `C:\Users\Public` **没有写入权限** | 用管理员权限启动 Syslab（§6.2.2） |
| 安装报 `Permission denied` | Syslab/Sysplorer 还开着 | 按提示关掉它们再点重试（§6.1.3） |
| 装到中文路径下失败 | `julia.exe` 不支持中文路径 | 换纯英文路径重装（§6.2.3，官方已报 Julia issue #46374） |
| 安装报 `[Errno 2] No such file...` | 用 WinRAR/UltraISO 打开时中途关了它 | 改用资源管理器挂载 ISO 重装（§6.1.1） |

## 装完的目录结构（说明书 §2.3）

| 位置 | 内容 | 卸载时 |
|---|---|---|
| 桌面快捷方式 | `MWORKS.Syslab2026b (x64)` | 删除 |
| 开始菜单程序组 | 启动 + 卸载两个快捷方式 | 删除 |
| `C:\Program Files\MWORKS\Syslab` | 主程序（默认位置，可改） | 删除 |
| **`C:\Users\Public\TongYuan`** | **Syslab 客户端仓库** | **不删除** |
| `%AppData%\Syslab` | Syslab 缓存目录 | 可选删除 |

> 记这一行：**卸载不会清掉 `C:\Users\Public\TongYuan`**。想彻底清干净要手动删。

---

## 卸载

开始菜单 → `MWORKS.Syslab2026b` 程序组 → **uninstall (x64)**。
说明书 §5 会依次询问是否删除缓存和个人数据配置。

## 附：ISO 里有什么

```
F:\  （挂载后的光驱）
├── Syslab-2026b-26.6.1-win-x64.exe      228.5 MB   安装程序
├── MWORKS.Syslab-2026b-win-x64-安装与配置说明书.pdf  4.4 MB   本文件来源
└── data\                                 3.11 GB   安装资源（30 个 .tar.zst）
    └── julia_depot.windows.x86_64.tar.zst   1.21 GB  ← 那个必须放 C 盘的 Julia 仓库
```

`data\` 里的 `.tar.zst` 由安装程序自己解压，**不用手动处理**。
如果想翻产品文档，系统自带的 `tar`（bsdtar 3.8.8，含 libzstd）可以直接解：

```powershell
# 例：解开 488 MB 的完整产品文档
tar -xf 'F:\data\docs.tar.zst' -C 'D:\MWORKS-docs'
```
