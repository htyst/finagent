## Windows 首次运行

安装项目支持的 Python 3.12–3.14（既有主验证版本为 3.12）、Node.js 24/npm 11。完整浏览器验收还需要 Edge 或兼容 Chromium。

1. 将压缩包完整解压到本地文件夹，进入其中的 `finagent` 目录。
2. 在这个目录打开 PowerShell，执行：

```powershell
.\scripts\setup.ps1
.\scripts\reset-demo.ps1 -Date 2026-09-24
.\scripts\dev.ps1 -Mode mock
```

3. 等服务就绪后，浏览器打开 `http://127.0.0.1:5173`，选择演示用户。
4. 第一次安装需要网络下载依赖；安装完成后的 mock 模式无需模型密钥。
5. 保持启动终端打开，Ctrl+C 停止服务。已有数据库以后直接 dev 启动，不要重复 reset；reset 会清空演示数据。

## 使用 DeepSeek

仅在本地 `.env` 不存在时复制 `.env.example` 为 `.env`，填写自己的 `MODEL_API_KEY`。停止 mock 服务后运行：

```powershell
.\scripts\dev.ps1 -Mode live
```

live 会调用配置的模型，使用近期对话和待确认模拟操作摘要；不要输入真实银行账号、验证码或其他敏感信息作为测试内容。转账和卡片操作均为模拟业务，需核对操作单后确认。
