# 启动器停止修复（2026-10-17）

修复了关闭进程组句柄后直接显示“服务已停止”、但未等待和核验后端/前端退出的问题。

- 服务以直接子进程方式启动，继承启动器的 Windows 进程组；管理进程完成绑定后才允许启动服务。
- 停止按钮先通知管理脚本清理服务，再按需终止进程组并核对本次完整子进程树。按 PID 和创建时间核验身份，不按进程名称或端口盲目结束其他程序。
- 只有确认本次进程退出且 8000/5173 端口均释放，才显示“已停止”；失败或其他程序占用时显示实际状态。
- 关闭窗口、启动中停止、启动失败和切换模式使用相同清理路径；迟到的就绪检测不会将停止状态改回启动成功。
- 同步重建 FinAgent.exe、FinAgent-Mock.exe、FinAgent-Live.exe。

隔离环境实测 6 项通过：Mock 停止按钮、Live 关闭窗口、停止后 Mock→Live 重启、启动中停止、前端启动失败后清理子进程、默认端口被其他程序占用时不误停。停止后端口不再监听，全新 HTTP 请求连接失败。Live 检查只使用测试配置，不调用模型。

这次修复安装在合并后的 A 项目。业务数据库、模型配置和 B 源码不变。
