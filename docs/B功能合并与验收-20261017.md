# B 功能合并与验收（2026-10-17）

本次以年度案例项目 A 为基础，合入 B 的资料管理、模拟短信、页面初始化及账户冻结规则。未导入 B 的单用户清理、种子数据或数据库，不覆盖模型配置。

## 使用入口

- 我的资产 → 卡片 → 添加银行卡：关联现有账户，或创建带初始模拟余额的新账户。
- 我的资产 → 收款人 → 添加收款人：填写姓名、银行、完整模拟账号，手机号及备注可选；保存后可用于原有转账。
- 红色确认 → 获取模拟短信验证码 → 填入验证码：填入不会执行交易，仍须核对固定条款并点击验证执行。也保留命令行取码。
- 右上角初始化页面：为当前选中的用户创建新会话，清理当前任务上下文、对话和未提交表单，返回助手页。已有账户、银行卡、收款人、流水及已确认后台业务保留。
- 冻结任一关联卡：关联账户暂停转账、消费、申购、预约扣款、订阅代扣和生日付款。查询、收款、退款及赎回入账保留。所有关联卡解冻且账户无其他限制后恢复出账，旧操作单和失败扣款不会自动重放。

## 与 A 的适配

保留 20 人年度案例、多用户选择、完整金融档案、导入信用卡只读约束、解挂/补卡/授信审批、商户会员服务、62 个动态工具、对话内固定授权与恢复。

目录模型增加银行卡与收款账号的按用户查重摘要，收款人增加银行名称；不保存完整卡号或收款账号。创建模拟资料的接口不会取得交易执行权限。

短信弹窗同时适配传统操作路径和 A 的任务绑定授权路径。后者还检查原任务、当前操作标识和会话；验证码读取不替代验证，不向模型工具开放。

冻结限制在准备、确认及统一借记入口检查；冻结/解冻更新账户版本，避免旧操作单在解冻后恢复。财务规划与账户查询使用相同的可支配余额规则，冻结账户显示零可用出账金额。
