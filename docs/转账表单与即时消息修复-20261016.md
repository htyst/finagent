# 转账表单与即时消息修复

## 转账

对话中的转账资料表单增加“付款账户”下拉选择，显示本人有效账户的名称与尾号；保留已明确的收款户名和金额，并允许在同一张表单中补齐金额。完整提交后直接准备固定操作单，不再调用模型重新理解。实际付款仍经过现有固定条款确认与强验证规则。

后端修复了账户名称加尾号的解析，以及表单补充时丢弃已明确付款账户、金额的问题。复合账户引用必须同时匹配名称和尾号，其他用户、已关闭或冲突的账户不能用于准备。原三字段接口仍兼容，补充付款账户后可以继续同一笔需求。模型从历史误带未明确字段时，将其清空并提供可填写的转账表单。

## 即时消息

点击发送后立即显示本地待回复消息并清空输入框，已有聊天记录保持可见，随后等待服务端回答。回答返回时替换本地消息，不重复显示问题；等待期间输入的下一条草稿保留。网络异常先只读核对服务端状态，已经保存的问题不重复发送；未确认送达的消息保留并标记状态。切换用户清除本地待发消息与草稿。认证信息在前端拦截，不进入待发消息气泡或模型。
