# FinAgent 接口、数据与恢复说明

日期：2026-10-15。完整请求/响应Schema以运行服务的 `/openapi.json` 为准；字段中的金额均为整数分，份额为百分之一份。

## 接口组

| 入口 | 用途 | 授权 |
|---|---|---|
| `/api/demo/info`、`/api/health` | 模式、非秘密模型配置状态、健康 | 公开演示元数据 |
| `/api/demo/session`、`/api/demo/csrf` | 演示用户会话与CSRF | 不等于银行登录 |
| `/api/accounts`、`/api/transactions`、`/api/spending` | 账户、流水、分类统计 | 会话归属；绿色 |
| `/api/tasks`、`/api/tasks/{id}/messages` | 创建任务、追加消息 | 会话＋Origin＋CSRF；业务另行确认 |
| `/api/tasks/{id}/audit` | 结构化决策、版本、步骤摘要、资源及转账审计 | 当前用户且原任务会话；不导出聊天/认证材料 |
| `/api/proposals/{id}/*` | 普通操作单的令牌、确认、取消 | 固定单＋黄/红权限；幂等回执 |
| `/api/security/operations/{kind}/{id}/*` | 等级、挑战、验证 | 固定单绑定，失败计数 |
| `/api/schedules/*`、`/api/collections/*` | 预约与AA | 用户确认；成员付款为显式模拟 |
| `/api/wealth/*` | 风险问卷、产品、持仓、订单 | 申购红色、赎回黄色 |
| `/api/card-management/*` | 卡片申请、限制、消费、审批 | 申请先用户确认；approve另需本机审批凭据 |
| `/api/subscriptions/*`、`/api/birthdays/*` | 订阅、提醒、生日安排 | 查询及固定单授权；后台专项授权 |
| `/api/tasks/{id}/control`、`/api/operator/*` | 暂停/接管/恢复 | 用户与本机坐席权限分开 |

所有业务API使用统一 envelope：status、data、error_code、message、request_id。失败状态和消息不作为成功回执；遇到不确定响应先GET原业务状态，不能重新POST新业务。模型、用户输入均不能覆盖资源归属。

## 数据表与迁移

基础表：users、accounts、cards、recipients、transactions、data_coverage、demo_sessions、demo_settings。普通操作：tasks、proposals、transfer_orders、card_action_orders、business_results、recipient_credits、audit_events。Agent：agent_tasks、agent_messages、agent_steps。扩展分别为 scheduled_transfers、collection_*、wealth_*、risk_assessments、card_*、subscription_*、birthday_*。安全与控制为 security_states、security_challenges、security_authorizations、task_controls。

当前迁移head `0013_security`；0006增加手机号、0007增加备注、0008—0012增加各业务表、0013增加持久安全和任务控制。本轮有从重建0006模式升级到head的隔离测试，核对手机号、余额和历史回执；不是用户原始旧库档案。迁移前仍须备份，不得为升级重置生产/日常演示库。

## 状态与恢复

| 对象 | 主要路径 | 恢复原则 |
|---|---|---|
| 普通转账 | pending_confirmation → executed / invalidated / cancelled / expired / failed | 原凭据幂等返回原回执；改变条款重新准备 |
| 理财 | pending_confirmation → settled | 资金和份额同事务；问卷改变作废旧单 |
| 卡申请 | pending_confirmation → submitted → issued | submitted不等于发卡，独立模拟审批 |
| 预约 | pending_confirmation → scheduled → executed / failed / cancelled | 重启后扫描持久记录；失败不自动改金额重试 |
| AA | pending_confirmation → collecting → completed / cancelled | 已付成员及入账保留；取消不能撤销已入账 |
| 生日 | scheduled → ordering → partial_failure / awaiting_delivery → completed | 只重试失败蛋糕；不得重新购买已付商品；送达需独立回执 |
| 控制 | running → paused / handoff / awaiting_reverification / terminated | 坐席交还不代替业务确认；不能暂停逃离接管 |

取消与worker执行共用写事务：取消先完成则阻止未来支付；支付先完成则保留真实模拟账本与回执。读失败只恢复未完成读取，不重复金融写入。当前不提供通用银行退款或已付款采购自动补偿，界面必须解释不可逆范围。

审计目前以任务ID连接步骤/资源，并导出策略版本和参数/结果摘要。各后台事件的统一trace_id传播尚未完整实现，因此K08保持部分完成，不把该接口称为全链路追踪。
