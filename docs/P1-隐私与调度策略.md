# FinAgent 隐私、数据与后台调度策略

日期：2026-10-15；适用于本地合成数据演示。

## 外部模型传输

Live发送当前任务最近16条经脱敏消息、日期/时区、必要业务草稿和待确认操作摘要。模型工具Schema是服务端能力目录，不含认证/确认工具。完整收款账号、收货人、地址的结构化字段置空；已知生日联系资料从继承文本中替换；显式联系方式标签与连续12—30位账号另作文本脱敏。验证码、API Key、CSRF及操作令牌不进入模型payload。

普通收款姓名、商户名、目录别名、必要手机号可能作为用户明确办理要求发送，不能宣称所有个人信息都不外传。自由聊天中未标记、未进入结构化字段的任意地址/姓名不能保证自动识别；应只用合成数据演示，不录入真实客户资料。完整本地表单仍用于业务，不通过模型补齐或篡改。

模型只允许官方HTTPS地址，不跟随重定向；本地密钥保存在忽略的 `.env`，供应商错误原文不反射到页面/审计。审批、坐席和短信凭据彼此独立。日志、录屏和源码包仍需最终敏感信息检查。

## 本地保留与清理

SQLite保存本地聊天、收货资料、固定操作单、授权、金融流水和审计。当前没有自动清理期限；默认保留到用户主动处理。`var/logs`、TEST-ONLY测试证据和模拟短信文件也不承诺自动到期删除。不得将令牌过期误称为文件已删除。

日常数据库先备份再人工处理；不能为隐私清理删除已执行流水而保留伪造余额。重置会清空整个演示集，正常启动不重置。录屏使用新建TEST-ONLY合成库，隐藏密钥和OS收件箱；模拟身份/时间推进须持续标注。建议交付前审核保留范围并由团队决定正式存储期限，当前不作为真实银行合规方案。

## 代扣授权来源

普通seed/reset不自动建立可扣款授权。`seed_test_authorizations` 仅允许路径包含TEST-ONLY的隔离库，用于显式测试，不代表客户合同。授权须有匹配 security_authorizations 的条款、期限和次数；缺少契约的历史记录停止并提示重新办理。现有演示通道不是第三方商户实际签约。

授权范围固定商户、账户、金额、月周期、约定日与时区；每份契约最多12次、366天。月底不足约定日取当月最后一天，北京时间09:00。撤销银行代扣不取消商户会员；取消提醒不撤销代扣。

## 停机与重启

worker默认每秒轮询，每轮处理最多20项。提醒重启后补发一次，并保留计划和实际送达时间。代扣每次处理一个到期期次，记录结果后推进到下一月，唯一约束防止同一期重复扣款。停机跨多个周期时可逐轮处理尚未尝试的到期期次，仍须逐次核验授权、次数、余额与锁；已经失败的历史期不自动重试，不能笼统声称“永不补扣”或“无限追扣”。

预约到期失败或权限升级时停止；生日成功商品不会因重启重买，失败商品需用户明确重试。电脑及后端需保持运行，关闭浏览器不停止后台。上游超时不等于已撤销，先读取持久状态。
