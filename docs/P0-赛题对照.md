## 架构和执行边界

```mermaid
flowchart TD
  UI[本地网页与自然语言对话] --> Goals[意图与完整目标清单]
  Goals --> Plan[Mock或Live计划]
  Plan --> Check[Schema/依赖/目标/归属校验]
  Check --> Sandbox[受限进程校验工具信封]
  Sandbox --> Domain[受信任只读或准备服务]
  Domain --> Fixed[固定操作单]
  Fixed --> Confirm[黄色确认或红色模拟挑战]
  Confirm --> Transaction[短写事务重新判级与核销]
  Transaction --> Ledger[账本/业务回执/审计]
  Transaction --> Grant[有界后台授权]
  Grant --> Worker[到期再校验并执行]
  Control[持久任务控制与模拟坐席] --> Check
  Control --> Transaction
  Control --> Worker
```
