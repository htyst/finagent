- 保留 DeepSeek 动态工具循环及服务端权限、固定操作单、独立模拟验证和幂等；合入本地对话取消、订阅对象解析、证据与数字判断、目标状态及恢复修订。
- 合入任务中心与对话入口分离、目标历史、需要明确用户同意的只读资金复查，以及回执后的持久续跑队列。后台复查不新增用户付款授权。

- 对应入口包括 workflow_plans.py、domain/workflows.py、api/workflows.py、TaskContextPanel.tsx 和 WorkflowPlans.tsx，新增确定性回归随源码发布。

## 发布与保护

公开内容为源码、合成测试夹具、合成 CSV、配置模板及脱敏文档。当前工具契约由实际注册表重新生成。原始财务验收明细、真实运行库、回执、聊天记录、本地路径和截图不新增到公开仓库，原件留在本地。

本轮在隔离候选副本测试，普通运行数据库与本地 .env 不参与测试。旧 Git 历史、已有文件及已有公开证据保留；历史测试数量不作为当前版本的验收结论。

## 当前检查

本轮保持 source / frontend / cloud 三个独立作业。source 运行全部 backend/tests 并准备年度隔离基线；新增编排调度器在测试中关闭，不改变生产默认。frontend 运行 API 与目标进度测试、类型检查、生产构建；cloud 实际构建镜像，验证健康、访问保护、0019 迁移及卷重启保留。

当前提交的实际 Actions 状态和最终测试数量将在运行结束后记录。[主分支 Actions](https://github.com/htyst/finagent/actions?query=branch%3Amain) 显示每次发布结果。不得把镜像健康检查当作全部金融业务或真实模型验收。

## 使用与升级

新用户按根目录 README 安装依赖并首次导入合成数据；已有数据先停止自己的服务，执行 `python scripts/backup-database.py` 做 SQLite 在线备份，再运行正常启动入口自动迁移。迁移失败时保留原库与备份，停止新进程，使用匹配旧代码和升级前备份恢复；不可在旧代码中直接打开新 schema 或反向重置。

云端继续使用 Dockerfile.cloud 和持久卷，已有卷只迁移，不清空。GitHub 上的 cloud 作业属于部署验证。Google Cloud 尚未提供 Project ID、结算确认及部署权限，本轮不会创建付费云资源，也不宣称已获得公网演示地址。
