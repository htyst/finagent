## 使用与升级

新用户按根目录 README 安装依赖并首次导入合成数据；已有数据先停止自己的服务，执行 `python scripts/backup-database.py` 做 SQLite 在线备份，再运行正常启动入口自动迁移。迁移失败时保留原库与备份，停止新进程，使用匹配旧代码和升级前备份恢复；不可在旧代码中直接打开新 schema 或反向重置。

云端继续使用 Dockerfile.cloud 和持久卷，已有卷只迁移，不清空。GitHub 上的 cloud 作业属于部署验证。Google Cloud 尚未提供 Project ID、结算确认及部署权限，本轮不会创建付费云资源，也不宣称已获得公网演示地址。
