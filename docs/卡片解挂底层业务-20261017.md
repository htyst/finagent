# 卡片解挂底层业务

本轮按小任务处理，仅新增卡片解挂，没有调用 DeepSeek，也没有改前端或 DAG。

## 已实现

- 新增 `unloss` 业务类型及 `prepare_card_unloss` 专用工具，当前工具数为 57。通用卡片管理入口也支持该动作。
- 本人范围核验；未挂失的卡不生成解挂单；导入只读信用卡仍不能办理。
- 准备时不改变卡片状态，必须通过红色强验证与固定操作单确认。纯聊天“同意”不能办理。
- 仅解除挂失；冻结、线上支付开关、单笔交易限额均保留。
- 执行时校验卡片及限制版本，过期、取消或状态已变化的旧单不能执行；重复确认返回原回执，审计仅写一次。
- 新增数据库迁移 `0016_card_unloss`，扩展办理类型约束，保留已有数据。已有解挂记录时拒绝降级，避免删除审计记录。
