
## 分发与限制

- README 面向拉取者；Mock 不需要密钥，Live 必须由使用者在自己的 .env 配置 API。源码包为 var/artifacts/FinAgent-GitHub-source-20261018.zip，旁附 .zip.sha256；包内 SOURCE-MANIFEST.json 列出每个源文件哈希。发布前再检查真实 Git 暂存内容，不把忽略规则当作历史泄漏检查。
- 本轮为同一台 Windows 机器上的干净 Git 克隆和独立依赖安装。机器已有 Python/Node，安装可能使用下载缓存。不是陌生机器验收；没有测试 macOS/Linux、Docker 或公网云部署，也未验证 setup-node 的重新下载过程。
- 未调用真实 DeepSeek；本轮 Live 仅验证缺配置拒绝启动。银行、短信、资金和业务数据仍为本地模拟，不能称为真实银行接入。
- 后端与前端业务源码未改。动态 DAG、财务判断和真实模型已知限制沿用 本地历史记录（未公开），本轮不宣称修复。
- 上传 GitHub 是源码分发；本轮没有自动更新远端仓库，也不等于网站已经云端上线。已存在的仓库应保留历史，合并源码后正常提交，不强推覆盖。
