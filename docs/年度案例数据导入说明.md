# 年度金融案例环境与导入

本轮在用户指定的最新版项目中重建 Python 3.12 虚拟环境、按锁文件安装后端及前端依赖，修正便携 Node 检测返回多个路径的问题。保留本地 `.env`，Live 仍使用现有 DeepSeek 配置。

## 运行

本机已经导入年度案例，直接运行 `scripts/dev.ps1 -Mode live`，访问 http://127.0.0.1:5173 并重新选择用户。不要运行 `reset-demo.ps1`，该旧入口会重置为原来三名用户的小样本。

如需在其他机器重新安装：先运行 `scripts/setup.ps1`，停止开发服务，再运行 `scripts/import-financial-demo.ps1`，最后启动。导入器只在新建的迁移库中写入数据，核对 CSV SHA256、行数与账本后，备份旧数据库并原子替换；不是向当前账本追加重复流水。旧会话、任务与确认单不会带入新案例。

## 数据内容

数据目录 `datasets/demo_financial_v2/` 含 23 张 CSV，周期 2025-09-25 至 2026-09-24：20 人、56 个银行账户、52 张卡、25,471 笔现金流水、903 笔负债事件、48 份订阅和 514 次扣费尝试；还有定期、基金、房车估值、贷款、信用卡账单、保险、月末快照和不同演示情景。CSV 原始 28,399 行均保留在按用户隔离的档案表中；真实公开零售参考样本保持独立，未冒充个人银行数据。金融案例均为合成数据。

新页面“我的完整金融档案”展示存款、银行卡、投资、负债及净资产。活期/定期余额与本系统银行账本一致，新增操作后刷新；基金、信用卡欠款、贷款、保险和实物估值保持截至日快照。信用额度和保险保额不计资产，债务还款不计消费。定期本金不可直接转出。到期卡不能通过解冻继续使用。

订阅面板经原有黄色查询确认后，展示完整 48 份合同及逐次扣费（每名用户只看自己的），包括重复服务、试用转付费、涨价、失败、取消、月付/季付/年付及银行卡绑定。兼容的 32 份月付借记卡合同映射到原有提醒/解除固定单；其他合同目前只读。导入不创建任何后台扣款授权，也不会补扣历史费用。银行代扣解除与服务商会员取消不同，原始合同快照和当前银行授权状态分别标明。

Agent 增加 `read_financial_profile` 只读工具，可查本人资产负债；订阅仍走 `read_subscriptions` 和独立确认，不通过普通档案查询绕过。

## 验证与备份

完整后端回归 179 项测试及 4 个子测试通过；前端 TypeScript 检查、Vite 构建、14 项 API 回归通过。新增导入测试覆盖 20 人净资产对账、跨用户隔离、订阅查询保护、不自动补扣、定期/到期卡限制、月付合同确认解除。

实际 Live 页面经 Edge 检查，20 人切换、金融档案、订阅查询确认、重复服务、到期卡与定期可用余额显示通过，无前端运行错误。新档案工具的受限校验、本人范围、净资产计算和固定回复均在本地验证。此前 DeepSeek 无账户数据的连接/工具调用探测成功；本轮未完成新档案的真实外部模型查询，自动审批以金融档案外发需明确授权为由拒绝了该次测试，因此不宣称新档案已通过真实模型端到端验收。页面仍可在 Live 模式使用现有配置。
