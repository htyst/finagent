# 信用卡授信信息查询

新增只读底层业务 `app.domain.credit_cards.read` 和工具 `read_credit_cards`。当前工具数为 58。本轮没有改前端、DAG 或数据库结构，没有调用 DeepSeek。

## 用法

用户可询问“查询我的信用卡额度”或“查看尾号 9876 的信用卡额度和最近账单”。工具参数 `card` 可省略；指定时支持本人卡片的唯一名称、尾号或内部标识。有歧义时要求明确，不扩大查询范围。

返回总信用额度、档案欠款、可用额度、已出账和未出账金额、最低还款额、账单日、还款日及最近已记录账单。所有金额均为整数分，回答通过服务端数值证据核验。银行卡只展示尾号，缺失金额或日期保持未知，不补零或推算。

## 边界

- 查询只读取当前用户、当前数据版本的档案，不需要二次确认；不接收 owner_id，不查其他用户。
- 数据明确标注导入快照日期。档案欠款与可用额度直接读取，不能视作实时已用额度或当前可刷金额；不能据此认定当前逾期。
- 最近账单仅选择快照日之前的记录；账单中还款日缺失时不依据每月还款日推算日期。
- 查询不提交额度调整申请、不执行还款，也不改变卡片限制。信用卡授信调整本身仍待后续单独实现。
- 新查询的已核验卡尾号和日期可用于自然语言回答，不允许这些元数据为其他数字或金额背书。

## 验证

67 项相关自动测试通过，涵盖本人范围、数据版本、同名及同尾号歧义、缺失字段、异常金额、模型工具调用、金额引用、日期引用及防止错误数字通过校验。既有工具和动态运行时回归同时通过。

现有案例副本中 20 个用户、12 张信用卡均完成查询，查询前后所有数据库表记录一致。真实模型调用次数为零。正式安装前保留备份；安装及服务验证证据位于 `var/reviews/credit-query-20261017/`。
